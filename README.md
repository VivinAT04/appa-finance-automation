# APPA Finance Automation Platform

Enterprise finance and document automation platform built around a real-world
document-heavy finance workflow.

## Planned Workflow

Document / Invoice
        ↓
Document Extraction
        ↓
Validation
        ↓
Supplier / Customer Verification
        ↓
Purchase Order / Business Rule Matching
        ↓
Approval
        ↓
UiPath / Power Automate Processing
        ↓
Completed / Exception
        ↓
Audit & Reporting

## Core Technologies

- UiPath
- UiPath Orchestrator
- REFramework
- Document Understanding / OCR
- Microsoft Power Automate
- Microsoft 365
- REST APIs
- PostgreSQL
- Web application
- Google Cloud
